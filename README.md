# Python Textual TUI Log Viewer

This example demonstrates an interactive Terminal User Interface (TUI) log viewer built with Python's Textual library. It simulates real-time log data, allowing users to filter log entries dynamically by typing into an input field. The application showcases how to overcome the limitations of basic command-line tools like `grep` and `tail` by providing an interactive and visually enhanced log analysis experience.

## Language

`python`

## How to Run

1. Install Textual: `pip install textual`
2. Run the script: `python main.py`
3. Type into the input field to filter logs, or press 'q' to quit.
